## Resumo
Neste trabalho foi desenvolvido um analisador léxico em Python para reconhecer os tokens de uma linguagem de consultas.

O programa utiliza expressões regulares para identificar variáveis, strings, identificadores, números, delimitadores e a palavra reservada LIMIT.
