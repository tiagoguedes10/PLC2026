# TPC2 - Conversor de Markdown para HTML

## Autor

- ID: A111163

## Resumo
Neste trabalho foi desenvolvido um conversor de Markdown para HTML utilizando expressões regulares em Python.

O programa converte cabeçalhos, texto a negrito, texto em itálico, listas numeradas, links e imagens para HTML.

Foi utilizado o módulo re e a função re.sub() para realizar as conversões.
